# Movie Recommendation System

This project recommends movies by comparing their content such as genres, keywords, cast, crew, and plot summaries instead of relying on a user's watch history.

## Overview

Many streaming platforms use a user's viewing history to make recommendations. In this project, recommendations are generated by comparing information about the movies themselves. This makes it possible to suggest similar movies even when there is no user activity available.

## Dataset

TMDB 5000 Movie Dataset (`tmdb_5000_movies.csv`, `tmdb_5000_credits.csv`) — title, genres, keywords, cast, crew, and overview for ~5,000 films.

## Pipeline

1. Merge movie and credits data on title.
2. Drop incomplete records.
3. Extract structured features: genres, keywords, top 3 billed cast, director, overview.
4. Clean and normalize the text, then apply Porter Stemming (NLTK) so that related words are treated as the same term.
5. Vectorize the combined feature text with `CountVectorizer`.
6. Calculate cosine similarity between all movies.
7. For a given title, return the highest-similarity matches.
8. Save the processed data and similarity matrix using Pickle so they can be loaded again without repeating the entire preprocessing step.

## Design Decisions

**Why CountVectorizer?** The dataset mainly contains short tags such as genres, keywords, and names instead of long paragraphs. Because of this, CountVectorizer provides good results while keeping the implementation simple.

**Why content-based recommendations?** The dataset does not include user ratings or watch history, so a content-based approach is the most suitable choice. It recommends movies based on their characteristics rather than user behavior.

## Tech Stack

Python, Pandas, NumPy, NLTK, scikit-learn, Pickle

## Setup

```bash
git clone https://github.com/PRANAVPANJABI/movie-recommendation-system.git
cd movie-recommendation-system
pip install -r requirements.txt
```

Open and run `notebooks/movie-recommendation-system.ipynb` sequentially, then call:

```python
recommend("Avatar")
```

Example output:

```text
Titanic
John Carter
Guardians of the Galaxy
Aliens
The Abyss
```

## Known Limitations

- Notebook-based; no web interface or API layer.
- Static dataset — recommendations don't reflect current catalogs or new releases.
- Content-based only; no collaborative or hybrid signal.
- No offline evaluation (e.g. precision@k against a held-out set) — recommendation quality is currently assessed qualitatively.
